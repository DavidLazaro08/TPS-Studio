Modo Diseño: el editor de tarjetas

El Modo Diseño es el corazón de TPS Studio. Aquí construyes visualmente tu tarjeta arrastrando, redimensionando y configurando cada elemento hasta conseguir exactamente el resultado que buscas.

🎨

El lienzo y el zoom

El lienzo muestra la tarjeta a escala real ajustada a la pantalla. Puedes acercar y alejar la vista para trabajar con más precisión:

AcciónAtajoResultado
Zoom inCtrl + + o rueda del ratón ↑Acerca la vista
Zoom outCtrl + - o rueda del ratón ↓Aleja la vista
Zoom 100%Ctrl + 0Vista a tamaño real
Ajustar a ventanaCtrl + Shift + FEncuadra la tarjeta en pantalla

Frente y Dorso de la tarjeta

Cada proyecto puede tener diseño en ambas caras. Usa el selector de cara en la barra superior para alternar entre Frente y Dorso. Los elementos de cada cara son completamente independientes.

📌 Nota: Si no diseñas nada en el Dorso, las opciones de exportación e impresión a doble cara se desactivarán automáticamente para evitar errores.
🔄

Seleccionar, mover y redimensionar elementos

  • Seleccionar: haz clic sobre cualquier elemento del lienzo. Aparecerá un borde verde con puntos de control en las esquinas.
  • Mover: haz clic y arrastra el elemento a la nueva posición. También puedes usar las teclas de dirección (↑↓←→) para moverlo pixel a pixel.
  • Redimensionar: arrastra cualquiera de los puntos de control de las esquinas.
  • Deseleccionar: haz clic en cualquier zona vacía del lienzo.
💡 Consejo: Si quieres ajustar la posición o el tamaño con exactitud, introduce los valores numéricos directamente en el panel de propiedades de la derecha.

Añadir elementos al diseño

Hay dos formas de añadir elementos:

  • Desde la Caja de herramientas del panel izquierdo (clic en el tipo de elemento).
  • Desde la barra superior, sección "Añadir elemento".

El elemento aparece en el centro del lienzo listo para mover y configurar.

El panel de Propiedades

Al seleccionar un elemento, el panel derecho muestra sus propiedades específicas. Cada tipo de elemento tiene sus propias opciones:

🔤 Texto

Fuente, tamaño, color, alineación, negrita, cursiva, salto de línea y auto-ajuste al ancho.

🖼 Imagen

Selección de archivo, opacidad, y vinculación a columna de foto de la base de datos.

⬛ Forma

Color de relleno, color y grosor de borde, radio de curvatura y opacidad.

📷 Código QR / Barras

Contenido del código, tipo (QR, Code128, EAN…), colores y vinculación a datos variables.

Capas y orden de los elementos

El panel de Capas (panel izquierdo, parte superior) muestra todos los elementos ordenados por profundidad: el elemento que aparece primero en la lista está encima en el lienzo.

📋

Desde el panel de capas puedes:

  • Seleccionar un elemento haciendo clic en su nombre
  • Reordenar arrastrando los elementos de la lista arriba o abajo
  • Ocultar/mostrar un elemento con el icono del ojo 👁
  • Eliminar un elemento con el icono de papelera
6

Vinculación de datos variables (Excel / Access)

La vinculación de datos es la característica más potente de TPS Studio. Permite que los elementos de texto, imagen y código del diseño se rellenen automáticamente con los datos de cada fila de tu base de datos, generando tarjetas completamente personalizadas en masa.

Formatos de datos admitidos

📊 Excel (.xlsx, .xls)

La opción más habitual. La primera fila debe contener los nombres de las columnas (cabeceras). Cada fila siguiente es un registro (una persona, un empleado, etc.).

🗄 Access (.accdb, .mdb)

Para bases de datos más grandes. Requiere el driver de Microsoft Office instalado en el equipo.

Vincular una base de datos al proyecto

  1. Abre el proyecto en el editor.
  2. Ve a Proyecto → Editar datos del proyecto (o haz clic derecho en el proyecto desde el modo Producción → Editar).
  3. En el campo "Base de datos", haz clic en "Seleccionar archivo" y elige tu archivo Excel o Access.
  4. Haz clic en "Guardar". TPS Studio cargará las columnas automáticamente.
🔗

Vincular un texto a una columna

  1. Selecciona el elemento de texto en el lienzo que quieres vincular (por ejemplo, el campo con el nombre de la persona).
  2. En el panel de propiedades de la derecha, busca la sección "Datos Variables".
  3. Selecciona en el desplegable la columna de tu Excel que quieres que se muestre (por ejemplo: "NOMBRE", "APELLIDOS", "CARGO"…).
  4. El texto del lienzo mostrará inmediatamente el valor del registro activo.
🔤

Vincular una imagen (foto por persona)

Para que cada tarjeta muestre la foto de la persona correspondiente:

  1. Crea una columna en tu Excel llamada FOTO, IMAGEN o similar. Escribe el nombre del archivo de cada foto (por ejemplo: garcia_juan.jpg).
  2. Copia todos los archivos de foto a la carpeta /Fotos dentro de la carpeta de tu proyecto.
  3. En el diseño, añade un elemento de tipo Imagen.
  4. En el panel de propiedades, vincula la columna de tu Excel a ese elemento imagen.
  5. TPS Studio buscará automáticamente el archivo en la carpeta /Fotos y lo mostrará.
📌 Nombres de archivo: Puedes escribir en el Excel el nombre con o sin extensión (garcia_juan o garcia_juan.jpg). TPS Studio probará automáticamente con las extensiones más comunes (.jpg, .png, .jpeg) si no la encuentra con el nombre exacto.

Navegar entre registros

En el panel lateral de "Datos Variables" verás la tabla completa de registros. Para ver cómo quedará cada tarjeta individual:

  • Haz clic en cualquier fila de la tabla para que el lienzo muestre esa tarjeta.
  • Usa las flechas ← → de la barra de datos para pasar al registro anterior o siguiente.
👥
⚠️ Importante: Los datos vinculados son solo para vista previa. El diseño base (posición, fuente, tamaño) siempre se mantiene. Cada tarjeta final se genera en el momento de exportar o imprimir.
7

Exportación a PDF

TPS Studio ofrece tres modalidades de exportación a PDF, cada una pensada para un caso de uso específico. Accede a ellas desde Archivo → Exportar PDF o desde el botón de exportación en la barra superior.

📄

Mail-Merge — Un PDF por cada registro

Genera un PDF individual para cada persona/registro de tu base de datos, con sus datos personales ya aplicados. Ideal para enviar por correo electrónico o para archivar.

OpciónDescripción
Solo FrenteGenera un PDF de una sola página con la cara delantera
Frente + DorsoGenera un PDF de dos páginas (solo disponible si hay diseño en el Dorso)
Rango de registrosPuedes exportar todos los registros o solo un rango (ej: del 1 al 50)
📌 Carpeta de salida: Se creará una subcarpeta /PDF_Export dentro del proyecto con todos los PDFs generados, nombrados automáticamente con los datos del registro.

Muestra de Diseño A4 — Para aprobación del cliente

Genera un único PDF en formato A4 con el diseño de la tarjeta centrado, un área para la firma del cliente y los datos del proyecto. Perfecto para obtener el visto bueno antes de imprimir.

✍️

PDF para Imprenta

Genera un PDF de alta resolución con el diseño incluyendo el área de sangrado completa, listo para enviar directamente a la imprenta. Este PDF incluye únicamente el fondo y los elementos estáticos, sin datos personales.

⚠️ Para imprenta profesional: Asegúrate de que el fondo de la tarjeta se extiende hasta el borde de sangrado (la línea roja del lienzo) para evitar bordes blancos tras el corte.
8

Impresión directa

Además de exportar a PDF, TPS Studio permite enviar las tarjetas directamente a cualquier impresora instalada en el sistema, incluyendo impresoras de tarjetas específicas.

  1. Haz clic en el botón "Imprimir" de la barra superior o usa Ctrl + P.
  2. En el diálogo de impresión, selecciona la impresora de destino.
  3. Elige si quieres imprimir Solo Frente o Frente + Dorso. La opción de doble cara solo aparece si tienes diseño en ambas caras.
  4. Selecciona el rango de registros si tienes una base de datos vinculada.
  5. Haz clic en "Imprimir".

Preguntas frecuentes y solución de problemas

❓ No aparece la foto en la tarjeta aunque tengo el archivo en /Fotos

Comprueba que el nombre del archivo en la columna de Excel coincide exactamente con el nombre del archivo en disco (respetando mayúsculas). Si el archivo es Juan_García.jpg, en el Excel debe poner exactamente Juan_García.jpg o Juan_García.

❓ La opción "Frente + Dorso" está desactivada en el diálogo de exportación

Esto es normal y es una protección automática. TPS Studio detecta que el Dorso de la tarjeta está vacío (sin elementos ni fondo) y desactiva la opción para evitar generar páginas en blanco. Añade algún elemento al Dorso y la opción se activará.

❓ El programa va lento al navegar entre registros con muchas fotos

Las fotos se cargan bajo demanda. Si las imágenes originales son muy grandes (más de 5 MB), considera redimensionarlas a un máximo de 1000×1000 px antes de añadirlas a la carpeta /Fotos. El resultado impreso será idéntico.

❓ IntelliJ / el IDE muestra errores en el código aunque el programa funciona

Si ves errores relacionados con caracteres como \u00f1 en los nombres de métodos, puede ser un problema de codificación del IDE. No afecta al funcionamiento del programa. Solución: ve a File → Settings → Editor → File Encodings y establece todo a UTF-8.

❓ El PDF exportado tiene un borde blanco en los bordes de la tarjeta

El fondo del diseño no llega hasta el área de sangrado. En el editor, asegúrate de que la imagen de fondo se extiende hasta la línea roja de sangrado (2mm por cada lado). Usa la opción "Ajustar con sangrado" al añadir el fondo.

📞 Soporte: Si encuentras un problema no descrito aquí, contacta con el equipo de soporte técnico o consulta la documentación técnica del proyecto en la carpeta /docs.
